<objective>
Create the database schema, extensions, tables, indexes, and RLS policies for the Network Command Lookup Tool.
</objective>

<threat_model>
- Assets at risk: Database schema integrity, access to commands
- Threat actors: Unauthorized users, malicious insiders
- Attack vectors: Unauthenticated access to database records, bypassing RLS to delete data
- Mitigations applied: RLS policies require `authenticated` role; destructive actions restricted by RLS (only creator can insert, but any auth can update/delete for now per pattern).
</threat_model>

<action>
Create file `supabase/migrations/001_create_schema.sql`.

Write the SQL to:
1. Enable extensions:
```sql
CREATE EXTENSION IF NOT EXISTS "pg_trgm";
CREATE EXTENSION IF NOT EXISTS "unaccent";
```

2. Create immutable wrappers:
```sql
CREATE OR REPLACE FUNCTION immutable_unaccent(text)
RETURNS text AS $$
    SELECT public.unaccent('public.unaccent', $1);
$$ LANGUAGE sql IMMUTABLE PARALLEL SAFE STRICT;

CREATE OR REPLACE FUNCTION immutable_array_to_string(text[], text)
RETURNS text AS $$
    SELECT array_to_string($1, $2);
$$ LANGUAGE sql IMMUTABLE PARALLEL SAFE STRICT;
```

3. Create tables:
- `vendors`: id, name, slug, os_flavors (TEXT[]), icon_name, badge_color, display_order, created_at.
- `device_types`: id, name, slug, icon_name, description_vi, display_order, created_at.
- `command_categories`: id, name_vi, name_en, slug, description_vi, icon_name, parent_id, display_order, created_at.
- `canonical_actions`: id, category_id, action_key, name_vi, name_en, description_vi, created_at.
- `commands`: id, vendor_id, canonical_action_id, created_by, command_syntax, full_syntax, prompt_mode, os_flavor, title_vi, description_vi, notes_vi, verification_command, rollback_command, is_destructive (DEFAULT FALSE), requires_commit (DEFAULT FALSE), is_verified (DEFAULT TRUE), tags (TEXT[] DEFAULT '{}'), parameters (JSONB DEFAULT '[]'::jsonb), examples (JSONB DEFAULT '[]'::jsonb), warnings (JSONB DEFAULT '[]'::jsonb), created_at, updated_at.
- `command_device_types`: command_id, device_type_id (PRIMARY KEY).
- `command_favorites`: user_id, command_id (PRIMARY KEY).

4. Add `search_vector` generated column and GIN/B-Tree indexes as specified in section 2.1 of PATTERNS.md.
```sql
ALTER TABLE commands ADD COLUMN IF NOT EXISTS search_vector tsvector GENERATED ALWAYS AS (
    setweight(to_tsvector('simple', coalesce(command_syntax, '')), 'A') ||
    setweight(to_tsvector('simple', immutable_unaccent(coalesce(title_vi, ''))), 'A') ||
    setweight(to_tsvector('simple', immutable_unaccent(coalesce(description_vi, ''))), 'B') ||
    setweight(to_tsvector('simple', coalesce(prompt_mode, '')), 'C') ||
    setweight(to_tsvector('simple', coalesce(verification_command, '')), 'C') ||
    setweight(to_tsvector('simple', immutable_unaccent(coalesce(notes_vi, ''))), 'D') ||
    setweight(to_tsvector('simple', immutable_unaccent(immutable_array_to_string(tags, ' '))), 'B')
) STORED;
```

5. Enable RLS and add policies for all tables as specified in section 2.1 of PATTERNS.md.
</action>
